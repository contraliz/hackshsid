GridShift for Windows x64
========================

1. Extract the entire GridShift-Windows-x64 folder from the ZIP. Keep the
   GridShift.exe and its _internal folder together; do not move the executable.
2. Double-click GridShift.exe. It opens GridShift in your default browser and
   shows a small status window with the local address and a Stop and exit button.
3. Close the status window or select Stop and exit to stop the local scheduler.

GridShift runs from its extracted folder and uses a loopback-only local server. The displayed address starts with
http://127.0.0.1/ and is reachable only on this computer. No Python, Node.js,
administrator install, account, or internet connection is required at runtime.

The workload, prices, renewable supply, and emissions are synthetic demo data.
The optimizer assumes divisible, preemptible GPU work and fixed real-time GPU
reservations. This is not an operations control system.

This build is unsigned. Windows may show a SmartScreen or publisher warning.
